# E-commerce Web Scraper

This project scrapes product data from an e-commerce website and exports structured data to CSV.

## Features
- Multi-page scraping
- Price cleaning (string to float conversion)
- Rating conversion to numeric scale
- Clean CSV export
- Error handling

## Tech Stack
- Python
- Requests
- BeautifulSoup
- Pandas

## Output Example
Name | Price | Rating
-----|-------|-------
Book Name | 45.17 | 2
